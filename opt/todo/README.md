# todo

**Version**: run `todo --version`
**Part of**: [Utilz Framework](../../README.md)

Simple DOING/TODO/DONE manager for a plain-text `todo.md`.

- User reference: [help/todo.md](../../help/todo.md). Run `utilz help todo`. It holds the file format, the commands, the options and the interop rules with `intent todo`.
- Design and rationale: steel thread ST0008. Run `intent st show ST0008`.
- Layout, metadata and tests: [Developer Guide](../../docs/developer-guide.md).
