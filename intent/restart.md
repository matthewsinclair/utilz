## Traps that each produced a real defect here

- **A timestamp not read off a clock is fabricated.** Two sessions once wrote the same plausible near-future stamp; the pre-commit guard caught one and read-back the other. Run `date -u +'%Y-%m-%d %H:%MZ'` for each, and never repair a fake with a better-looking one.
- **A default is a claim about what an unreadable answer means.** `${x:-safe}` downstream of a parse turns a failed read into a pass; a parse that read nothing must refuse.
- **A probe that ends in a pipeline kills the script before its guard can speak** (0053): under `set -euo pipefail`, `x=$(probe | awk ...)` dies at the assignment. A probe prints what it read or nothing and ends `|| true`, and the caller's emptiness guard refuses by name. The sweep for the class landed as 0080 in 2.14.1.
- **`local x=$(cmd) || handler` never fires the handler**: `local` returns its own status (SC2155).
- **A command that succeeds wrongly defeats every `||` guard**: GNU `stat -f` is filesystem status and exits 0, so put `stat -c` first.
- **Verify shell tooling under `/bin/bash` with an array.** zsh does not word-split, so an unquoted file list is one bogus path whose empty output reads as clean. Empty output is not a pass; report how many files the tool saw.
- **Never pipe a command whose exit code is the assertion**; zsh has no `PIPESTATUS`. A check whose success is "no matches" aborts under `set -e`: guard with `{ grep ... || true; }`.
- **A fixed `sleep` measures the sleep, not readiness.** Poll for the condition.
- **`utilz test` is not concurrency-safe** (it mutates `$UTILZ_HOME/bin`): one suite at a time. **`utilz help <x>` hangs when stdin is a TTY** (glow's pager): `< /dev/null`.
- **`/bin/bash bin/utilz test` is bash 3.2 for the dispatcher only**: bats is `#!/usr/bin/env bash`, so put `/bin` first and record the bash bats got.
- **The pre-commit doctor gate refuses every commit while any view in the estate is skewed**, and a refused commit leaves its paths staged for a peer's next plain commit to sweep in: unstage at once. An explicit-path commit of markdown the formatter rewrites leaves the real index stale (`MM`): run `prettier --write` first.
- **Never pass `--help` to another project's command to learn what it does; read its source** (Intent's `devbin macos prepare --help` once re-signed Intent.app). To ask what a command does, run the command's read-only mode, not its functions sourced into your shell, and a peer repeating your probe is reproduction, not corroboration.
- **`git tag -F` strips every line that starts with `#`**: pass `--cleanup=whitespace` and diff the annotation against its source.
- **`~/bin` is a symlink to `.local/bin` on hv's machine**: one directory, not two writers.
- **The critic reads changed files, so touching a file surfaces what was already wrong in it**, and a half-fix that leaves the use unquoted reads as done. A heredoc that writes a script is invisible to it.
- **`rustfmt --check` reading stdin exits 0 whatever it is handed**: check a file with `--config-path` pointing at the governing `rustfmt.toml`.
- **Two recordings of one reel are not always byte-identical** (0054): record the same build twice as the control before comparing two builds.
- **A zero from an instrument you have never seen return non-zero is not a measurement.** A broken reader returning zero looks like a true zero at exactly the moment nothing has been proven yet.
