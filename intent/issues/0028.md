## Summary

`opt/utilz/test/install_e2e.bats`'s `setup_file` copies the checkout, stages everything, and commits inside the copy so the publish's dirty-tree gate is satisfied:

```
git -C "$src" add -A >/dev/null 2>&1
git -C "$src" -c user.email=e2e@example.com -c user.name=e2e \
  commit -qm "e2e fixture" >/dev/null 2>&1 || true
```

(`install_e2e.bats:40-42`). **The project's pre-commit hooks run inside the copy. When one refuses, `|| true` swallows the refusal, the copy stays dirty, and the failure surfaces a step later as the publish's correct "source tree is dirty" refusal**, which names the wrong cause and points nowhere near the gate that actually said no.

## How it was found

2026-09-14, during cc's gate run for issue 0024: `utilz test utilz` failed with `not ok 120 setup_file failed ... source tree is dirty`. The real cause was the pre-commit doctor gate refusing every commit: the view skew on issues 0025 to 0027 that vc fixed at `895a2fc`. The setup's own output said "dirty tree". cc found the mechanism by reproducing the copy-commit in a scratch rsync of the tree with its output visible. vc named the `|| true` as a swallowed error and routed it to cc, as finder and fixer.

## Why the `|| true` is there

When the real checkout is clean, `git add -A` stages nothing and `git commit` exits 1 with "nothing to commit"; the `|| true` absorbs exactly that. **It cannot tell that case from a commit a hook refused**, and the second case is the one that matters.

## Fix direction

Tell the two cases apart instead of discarding both:

- After `git add -A`, commit only when the index differs from HEAD (`git diff --cached --quiet` returns non-zero).
- If that commit then fails, fail `setup_file` loudly, name the refused commit, and print its output.

This is IN-AG-NO-SILENT-001. The test for it is a copy whose commit a hook refuses, which must fail the setup naming the commit, not the dirty tree. It is red against the current setup.

## Severity

Low. Test-harness only, and the failure was already loud; it was misattributed, which cost a diagnosis rather than a defect.
