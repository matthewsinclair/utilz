## What is wrong

1. `prez --help` shows `prez present <deck.md> [--theme=NAME|--theme-file=PATH] [--window=WxH] [--browser=PATH]` (`opt/prez/crate/src/args.rs:16`). `present` takes `-o`, which keeps the built HTML at that path (`opt/prez/crate/src/deck.rs:66-75`), and help/prez.md:50 shows it.
2. `opt/prez/prez.yaml:43` lists `stdin` as an input mode. prez reads no deck from standard input: it takes one path, and a bare `-` is not stdin (`args.rs:185-187`).
3. `prez.yaml:16-17`, `args.rs:1` and `opt/prez/crate/src/frontmatter.rs:8` say that comrak is the only crate or dependency. Since 9 Sep 2026, prez also depends on its first-party `artifact` crate, which hv signed off as AC02's one addition (`opt/prez/crate/Cargo.toml`).

No code reads prez.yaml's `modes`, so that line is wrong but nothing acts on it.

## The fix

1. Add `[-o out.html]` to USAGE's present line.
2. Remove `stdin` from prez.yaml's `modes`.
3. Say in each of the three places that comrak is the only third-party crate.
