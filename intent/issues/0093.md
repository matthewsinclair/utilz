## What

The prez workspace's crate tests leave entries in TMPDIR on every run. utilz-dc's kovacs leg of 0092 (slot 177, 19 Oct 2026) counted 82 entries left in its run's own TMPDIR after `cargo test --release --workspace` on `fc5b9688`, the same 82 with and without 0092's fix. 0092 removed the 9 `artifact-theme-*` dirs; these are the rest. hv, 19 Oct 2026, on vc's question: "Nix them, please." vc made it cc's, in 2.14.1 (decision 42).

## Where, by reading

The tests make their scratch under `std::env::temp_dir()` with helpers that never remove it at the end:

- **prez** (`src/`): `deck.rs`'s `sandbox()` (`prez-deck-<pid>-<name>`), `drive.rs`'s two pagination tests (`prez-drive-<pid>`), `inline.rs`'s `fixture()` (`prez-inline-<pid>-<test>`) and `theme.rs`'s `dir()` (`prez-theme-<pid>-<name>`) make a dir and remove nothing.
- **showreel** (`crates/showreel/src/`): `admit.rs`, `build.rs`, `plan.rs`, `slide.rs`, `deliver.rs`, `payload.rs` and `theme.rs`'s `theme_dir()` remove their dir BEFORE a test (a stale one from an earlier run) and never after; `theme.rs`'s two registry tests and `normalise.rs`'s two helpers remove nothing.
- **artifact**: `path.rs`'s and `browser.rs`'s tests remove their dir at the end of a passing test only.

Which test leaves which of the 82, on a Mac and on Linux, is measured by a run with TMPDIR set to an empty directory of its own, before the design is settled.

## Fix, for the design to settle

0092's guard, a `TempDir` that removes its directory when dropped, moves from `artifact`'s theme tests to one place every crate's tests can use, and every helper above returns it. Red first by the count of entries a run leaves in an empty TMPDIR: the 82 (or the Mac's number) on main, 0 after.

## Design

cc, 19 Oct 2026, at `910af45` (0092 landed). Size: S. Read and approved by vc, 19 Oct, which added point 5's proof. Revised after slot 180: its first candidate added a `[dev-dependencies]` table, which prez's `tests/manifest.rs` refuses without hv, so no manifest moves now (point 2). Slot 180 on the Mac and utilz-dc's slot 185 on kovacs name the same 82 entries on `910af45`, every one from a helper in point 3.

1. **One guard, in `artifact`, for every crate's tests.** 0092's `TempDir` moves out of `theme.rs`'s test module into `artifact::testing`, an always-compiled `#[doc(hidden)] pub mod` whose header says it is test support. `TempDir::new(prefix, tag)` removes any leftover at `$TMPDIR/<prefix>-<pid>-<tag>`, the shape every helper's name already had, creates it and owns it; it derefs to `PathBuf`, and its `Drop` keeps 0092's rule: `NotFound` ignored, any other error a panic with the path and the error, or a line on stderr when the thread is already panicking. One guard, so no crate grows a second copy (Highlander).
2. **No manifest moves.** The tests of `prez` and `showreel` reach `artifact::testing` through the dependency they already have, so no `[dev-dependencies]` table or feature is added and `tests/manifest.rs` holds unchanged. No tool's code calls it, so the release build's LTO drops it from the shipped binaries, which point 5 checks.
3. **Every leaking helper returns the guard.** `prez`: `deck.rs`'s `sandbox()`, `inline.rs`'s `fixture()`, `theme.rs`'s `dir()`, and `drive.rs`'s two pagination tests. `showreel`: `admit.rs`, `build.rs`, `plan.rs`, `slide.rs` and `payload.rs`'s `reel()`, `deliver.rs`'s `out()`, `theme.rs`'s `theme_dir()` (`showreel-emit`) and its two registry tests (`showreel-reg`, `showreel-theme`), and `normalise.rs`'s `write()` (`showreel-norm`) and its rounding test (`showreel-round`), where the file path a helper returns becomes a path inside a guard the test holds. `artifact`: `theme.rs`'s `dir()` uses the moved guard, and `path.rs`'s and `browser.rs`'s tests take it in place of their own removal at the end, so a failing test cleans up too. Each name keeps its prefix and tag, so a leftover from an older build still says whose it is. The `let _ = remove_dir_all(&d)` before each showreel test goes, since `new` does it.
4. **The test, red first, by the count.** Each run sets TMPDIR to an empty directory of its own and counts the entries `cargo test --release --workspace` leaves there: the measured number on `910af45` (82 on kovacs), 0 after, on the Mac and on kovacs. 0092's probe test moves with the guard to `artifact::testing`, so the guard's own behaviour stays tested in one place.
5. **Runs.** M1 first (slot 180). Then, booked heavy: the count on main and after, the crates' tests green, `bin/devbin check all`; no manifest moved; and the guard's message (`cannot remove the test directory`) absent from the release `prez` and `showreel` and present in a test binary, the control; a message rather than a symbol, since the release profile strips symbols and no symbol would be found in any case; utilz-dc's kovacs leg on the same bytes with its count. Built in `wt-0093` on `910af45`; landed in 2.14.1 (vc's decision 45), on the head of that moment.
6. **Versions and CHANGELOG.** Only tests and test support change, so prez stays at 2.5.3. One CHANGELOG line under 2.14.1's Fixed (hv put 0093 in 2.14.1, vc's decision 45), added at the landing.
