## What is wrong

Menuz's About window has no icon, no build line, no source line and no links. It is only a heading, one paragraph and three bullets, and its title is the lowercase "menuz 0.4.7". Gtools' About (0.7.2) and Intent's (3.2.6), both built on the same arca_swift ArcaMasthead, have all of these:
- the app's logo at 128px;
- the name as the heading, then a one-line description;
- "{version} (build N, commit)";
- the source tree;
- "Built by <command> from <path>";
- the repository link;
- the author's link.

hv found this on 28 Oct 2026, after installing 2.14.5's Menuz.app.

## Why it happened

`native/macos/Menuz/Menuz/Masthead/about.md` and `masthead.yaml` have not changed since they were written in 6583e700 (issue 0073, 19 Oct). They were written from scratch, not copied from Gtools' working `Masthead/` (`about.md`, `about.css`, `gtools-logo.png`, `masthead.yaml`). Nobody compared them with the sibling, vc included. ArcaMasthead shows an image only when about.md names one, so Menuz's page never had a logo.

## The fix (data only, plus Menuz's version)

- Add `Masthead/menuz-logo.png`, made from AppIcon's 512px image, and `Masthead/about.css` with Gtools' `img { width: 128px; }`.
- Rewrite `about.md` in Gtools' shape: the logo, `# Menuz`, the one-line description, a `{version} (build ..., {commit}, {kind})` line from the values menuz gives, and the menu file `{menu}`. Then `Built by \`utilz menuz build\` from Utilz/native/macos/Menuz.`, `[github.com/matthewsinclair/utilz](https://github.com/matthewsinclair/utilz)` and `[Matthew Sinclair](https://matthewsinclair.com)`.
- Point `masthead.yaml`'s heading at `{name} {version}`, as Gtools' does, and add `css: about.css`.
- Bump Menuz to 0.4.8, since the app changes.

Done when a Release build's About window, put side by side with Gtools', shows the logo and each line above, and menuz test stays green.
