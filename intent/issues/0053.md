`stampz` reads a file's geometry through three probes that each END IN A PIPELINE: `_page_count` and `_page_size` are `pdfinfo ... | awk ...`, and `_distinct_geometries` is `pdfinfo ... | awk ... | sort -u | wc -l | tr -d ' '`. The script runs under `set -euo pipefail`, so when `pdfinfo` fails on a file it cannot parse, the pipeline's status is that failure, the assignment `pages=$(_page_count "$f")` carries it, and `set -e` kills the script THERE.

The line that was supposed to speak is the next one: `[[ -n "$pages" && -n "$size" ]] || { error "$base: could not read its page geometry"; exit 1; }`. It is unreachable for the case it was written for.

MEASURED 2026-09-22 on a directory holding one file of plain text named `broken.pdf`: `stampz <pack> "Matthew Sinclair" --out <dir>` exits 1 and prints NOTHING, on stdout or stderr. A `bash -x` trace ends at `pages=` with no further line. The manifest has already been opened and its header written, so the run leaves a STAMP-MANIFEST.txt naming a recipient and listing no files.

This is the project's own No Silent Errors rule broken by the mechanism the project documents: a command whose exit code becomes an assertion inside a pipeline. It is a sibling of the `${varied:-1}` defect this tool was promoted with, and the opposite failure: that one turned an unreadable answer into a pass, this one turns it into a refusal nobody can see.

THE FIX: a probe's contract is to print what it read, or nothing, and never to decide anything. Each probe ends `|| true`, so an unreadable file reaches the caller as an empty answer, and the guard that already exists refuses by name. Found while writing ST0025's AT03, which asserts the refusal a reader can see.


RESOLUTION, 2026-09-22, fixed at 63661de with ST0025. Each probe ends `|| true`, so a file pdfinfo cannot parse reaches the caller as an empty answer and the guard that was already there refuses by name. ST0025-AT03 holds it: a directory holding one text file named broken.pdf is refused with "could not read its page geometry" rather than exiting in silence. Red first against the old code, where the same run exited 1 with no output on stdout or stderr.
