## Summary

Utilz's pre-commit hook runs `prettier --write` over every staged `.md` and re-stages the result, after Intent's gates have passed. `.prettierignore` keeps the formatter off `intent/st/**` and `intent/todo.md` only. Issue views (`intent/issues/<id>.md`) and the whiteboard's board and inbox views (`intent/whiteboard/<node>/wip.md`, `inbox.<sender>.md`) are rendered views too, and they are not exempt: `prettier --file-info intent/issues/0025.md` answers `"ignored": false`. On 2026-09-14 that let the formatter collapse a doubled blank line in three issue views after the doctor gate had passed. The committed views then disagreed with the store, and the doctor gate refused every later commit until `895a2fc` fixed the three bodies.

The file's own header states the principle this breaks: renderer-owned paths only, and none of them the formatter's to touch. Issue views were already rendered when the header was written, and the whiteboard views became rendered on 2026-09-14 (`1b0049c`). Found by vc while writing Intent's report of the class.

Intent's `converge_formatter_exclusion` would have added the missing patterns, but it runs only at `intent init` and at the v2 migration, and Utilz migrated before it existed. Filed upstream as Intent issue 0378.

## Fix

Append the block `converge_formatter_exclusion` writes, carrying the seven of `Project::generated_view_patterns` that the file lacks. `intent/todo.md` is already there, so converge would skip it too. With the block in place, a later converge finds every pattern present and changes nothing:

```
intent/st/steel_threads.md
intent/st/*/info.md
intent/st/*/acceptance.md
intent/st/*/WP/*/info.md
intent/issues/*.md
intent/whiteboard/*/wip.md
intent/whiteboard/*/inbox.*.md
```

The header gains one dated paragraph saying why the block is there.

## Done

- `prettier --file-info` answers `"ignored": true` for an issue view and for a whiteboard board and inbox view. It still answers `false` for `intent/wip.md`, `intent/restart.md` and `intent/whiteboard/README.md`, which are authored.
- The hook's own form, `xargs prettier --write`, exits 0 when every staged `.md` is exempt, so a commit of whiteboard views alone still passes. This was measured on `intent/todo.md` before the fix.
- Proved by demonstration, not by a test of a test (hv, 2026-09-11).

## Severity

Medium. Development-only, but one formatter-unstable render wedges every node's commits.
