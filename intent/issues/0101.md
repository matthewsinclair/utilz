## What

`deliver::stem` builds a revision's name from the reel's `output:` pattern. It fills the pattern's fields with values that `tight` keeps to letters and digits, and the date's digits, but it keeps the pattern's own literal text as written, path separators included. So `output: 'sub/{nnn}.html'` or `'../{nnn}.html'` names a file outside `_out/` itself, which `revisions` never counts, since it lists `_out/` alone. On main every build named 001 again and replaced it. Since 0098 every build after the first refuses, because the file is there, and that refusal's remedy (build again, or move the file aside) sends a user round in circles. An absolute pattern (`/x/{nnn}.html`) writes wherever it names, since joining an absolute path replaces the base. critic-rust found it reading 0098's candidate v1 on 22 Oct 2026. vc made it cc's own issue, low, for 2.14.2 after 0100 (22 Oct), refused by name where the stem is built.

## Where, by reading (main at `020fd4db`)

- **The stem**: `stem` (`deliver.rs:230-318`) puts the literal text before each field into the prefix or the suffix as written (`:280`), and the text after the last field into the suffix (`:307`) or the fixed name (`:314`).
- **The name**: `Stem::next` joins it onto `_out/` (`:220` for a fixed name, `:223` for a counted one).

## Design

cc, 22 Oct 2026, at `020fd4db`. Size: S. It lands after 0100 and is built on 0100's landing. Read and approved by vc, 22 Oct, as it stands.

1. **A pattern whose name holds a path separator is refused by name, where the stem is built.** Once `stem` has assembled the prefix and the suffix, or the fixed name, it refuses when any of them contains `/`, the one separator on the platforms showreel runs on: `output pattern names a directory: <pattern>`, with the remedy `the pattern names a file in _out/; take the / out`. The fields cannot bring one in, since `tight` keeps letters and digits and the date is digits, so the check is on the pattern's own text. It refuses an absolute pattern too.
2. **Red first.** A unit test beside `a_pattern_with_two_counters_is_refused_with_the_pattern_named` (`deliver.rs:586`): `sub/{nnn}.html`, `../{nnn}.html`, `/tmp/{nnn}.html` and a fixed `sub/reel.html` each refuse, naming the pattern. Red by a one-line mutation that takes the check out. 0098's `write_next` test builds `Stem::Counted` with the prefix `sub/r-` directly, which stays right (vc).
3. **Runs**, each booked with utilz-vc. The candidate is built in its own worktree under `~/Devel/scratch/utilz-cc/`. R (heavy): the test's mutation. G (heavy): `bin/utilz test prez` under an empty TMPDIR of the run's own, then `bin/devbin check all`. K: utilz-dc's kovacs leg, `cargo test --release --workspace --no-fail-fast` on the same bytes.
4. **Versions and CHANGELOG.** prez 2.5.9, after 0100's 2.5.8, one bump per landing. One line under 2.14.2's Fixed, after 0100's, added at the landing.
