## Summary

The prez crate's black-box suites each carry a copy of one test harness.

- `crate/test/acceptance.sh` (ST0010) and `crate/test/theme-addressing.sh` (ST0013, ST0018, ST0020) define `want`, `start`, `ok`, `bad`, `present`, `absent` and `finish` identically, along with the same `--strict` argument parsing and counters. The one difference in `finish` is a 4-line comment in acceptance.sh.
- acceptance.sh alone defines `check`, `skip`, `unchecked` and `not_applicable`.
- theme-addressing.sh alone defines `shaped`, `same`, `renders`, `refuses`, `exits`, `ordered` and `unwritten`.

`theme-addressing.sh:26-29` records the duplication and leaves the extraction to vc. ST0021's `video.sh` needs helpers from both files, so it would be a third copy: the Highlander violation that header names (IN-AG-HIGHLANDER-001). vc ruled EXTRACT on 2026-09-19 (vc's board, decision 2), to land before `video.sh` has a first line, so that a third copy never exists.

## Fix

- **The union of the helpers moves, unchanged, into `crate/test/lib/harness.sh`**, with the argument parsing and the counters. `NOT_APPLICABLE` is defined for every suite, and a suite that never calls `not_applicable` leaves it at 0.
- **Not `crate/test/harness.sh`.** The test driver runs every `crate/test/*.sh` as a suite and refuses one that is not executable (`opt/utilz/lib/common.sh:1064-1075`). A sourced file at that path would either be refused or be run as a suite. The driver's glob does not recurse, so `lib/` is outside it.
- **Each suite keeps its own report block.** The two differ, because acceptance.sh prints n/a, and moving them would change a suite's output line.
- **The harness fails loudly.**
  - Each suite sources it from its own directory. If it is missing, the suite exits 1, naming the file.
  - `harness.sh` refuses to run when executed directly.
  - A `# shellcheck source=lib/harness.sh` directive stands beside each source line. CI's shellcheck collector excludes `*/test/*`, so the directive serves local runs.
- **`theme-addressing.sh:26-29`'s "Open with vc" becomes the record of the ruling.**
- **The proof:**
  - Both suites give the same verdicts and the same per-AT check counts before and after, under bash 3.2.57 with `/bin` first on `PATH`.
  - Each helper is defined exactly once under `crate/test`.
  - A suite with the harness missing exits 1, naming the file.
  - `harness.sh` run directly refuses.
