- **Never pipe a command whose exit code is the assertion.** `$?` after a pipeline is the LAST command's, so `cmd | tail` reports tail -- and tail almost always exits 0, which means a RED run behind that pipe prints `exit 0` too. **CORRECTED 8 Sep, by cc, and the old wording here was actively misleading: it said "zsh has no `PIPESTATUS`". zsh HAS the feature; what it lacks is the bash SPELLING.** Measured on `false | true`: bash `${PIPESTATUS[0]} ${PIPESTATUS[1]}` -> `1 0` (uppercase, 0-indexed); zsh `${pipestatus[1]} ${pipestatus[2]}` -> `1 0` (LOWERCASE, 1-INDEXED); zsh `${PIPESTATUS[1]}` -> EMPTY. Capture on the same line or not at all. **The recommendation survives both spellings and both traps: do not pipe. `cmd > "$LOG" 2>&1; rc=$?` makes the totals and the status independent claims by construction.**
