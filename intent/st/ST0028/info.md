# ST0028: arngz: a desk saved from live terminal windows fails to apply minutes later

## Objective

A desk that `arngz discover` saves from windows whose titles move, terminal windows above all, applies minutes later with those windows `unseen`. Discover writes each title it pins as an exact pattern, anchored at both ends, and a terminal's title carries whatever the terminal shows at that moment. This thread changes the patterns discover writes so that a desk saved from live windows still finds them, and makes discover say every title it pinned.

## Context

Found by dc on 16 Oct 2026, reading the log of hv's first menuz runs (ST0027). Run 8 applied `today.yaml`, which discover had saved through menuz minutes before. Two iTerm windows were reported `unseen`, so apply exited 1:

```
[8] com.googlecode.iterm2 "^%-zsh$" (displays[0].spaces[0].apps[5]): unseen: ...
[8] com.googlecode.iterm2 "^◑ utilz%-dc$" (displays[0].spaces[2].apps[0]): unseen: ...
```

`◑` is Claude Code's working glyph, which it puts at the front of the terminal's title while a turn runs. It changes on every turn, and is replaced by another glyph when the turn ends. hv told dc "Fix everything" and then "ok do all of that". vc ruled on the fix's shape and filed it as this thread. arngz is ST0026, released in 2.13.0 at 1.0.0.
