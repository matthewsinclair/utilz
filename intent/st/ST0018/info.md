# ST0018: prez: a fallback theme for decks that name none (PREZ_DEFAULT_THEME)

## Objective

Give prez a caller-supplied fallback theme, `PREZ_DEFAULT_THEME`, consulted only when neither a flag nor the deck names a theme, so a wrapper can set a house default without overriding a deck's own `theme:` or `theme-file:`. With the variable unset or empty, nothing changes.

## Context

Requested on 2026-09-14 by the validation node of a project that wraps prez. Its wrapper passes `--theme` to make its house theme the default, and because a flag beats the deck, no deck's own `theme:` ever selects. hv ruled the feature into the 2.9.0 release the same day, directly: "I want all of that and I want it IN THIS RELEASE, not a flow-on one." `design.md` carries the request verbatim, the decision (a variable rather than a flag) and why.
